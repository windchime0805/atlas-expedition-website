# Atlas — Expedition Log

A responsive expedition catalog and inquiry page built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server. The page uses Google Fonts and expedition photography hosted by Unsplash, so those visual assets need an internet connection.

## Features

- Responsive expedition catalog with working difficulty filters.
- Mobile navigation with accessible expanded state.
- Inquiry form with browser validation and an on-page demo confirmation. It does not transmit or store submissions.
- Keyboard focus styles, skip link, descriptive image text, and reduced-motion support.
- GitHub project link in the footer.

## Deployment

The site is static and can be hosted with GitHub Pages or another static hosting service. Configure the host to publish the repository root. No build step or backend is required.
